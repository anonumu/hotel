# Grand Impérial — Информационная система управления гостиницей (PMS)

Полноценное веб-приложение для управления гостиничным комплексом **Grand Impérial**: интерактивная сводка (Dashboard), номерной фонд, календарь и оформление бронирований, регистрация постояльцев, штат сотрудников, касса и счета (Folio), а также финансовая аналитика.

Бэкенд и интерфейс работают **на одном адресе** `http://localhost:8080/` — ничего отдельно настраивать не нужно, логин и пароль при запуске не требуются.

---

## Быстрый запуск в 1 клик (для Windows — 100% способ)

1. Откройте папку с проектом (`Самсонов проект`).
2. Найдите файл **[`start-hotel.bat`](start-hotel.bat)** и запустите его **двойным щелчком мыши**.
3. Скрипт сам всё сделает за вас:
   - автоматически найдёт установленную **Java 17+** на компьютере (в `JAVA_HOME`, `%USERPROFILE%\.jdks`, `Program Files\Java`, `Eclipse Adoptium`, `Microsoft`, `Corretto`, `Zulu`);
   - если готовый JAR ещё не собран — сам соберёт проект с помощью встроенного Maven (`hotel-backend\maven`);
   - проверит порт `8080` (если порт уже занят другой программой — сам переключится на `8081`);
   - запустит сервер Spring Boot и **сам откроет браузер** на `http://localhost:8080/`, как только база данных будет полностью готова.
4. Пока окно командной строки открыто — сервер работает. Чтобы выключить сервер, просто закройте это окно или нажмите `Ctrl + C`.

> При первом запуске после скачивания с GitHub (если папки с зависимостями Maven ещё нет в кэше пользователя `~/.m2`) компьютеру понадобится доступ в интернет на 15–40 секунд для скачивания библиотек Spring Boot. Все последующие запуски работают **полностью офлайн за 3–5 секунд**.

### Что делать, если скрипт написал «Не найдена Java 17 или выше»

1. Перейдите на [adoptium.net](https://adoptium.net/) и нажмите кнопку **Download** (Java 17 или Java 21 LTS для Windows x64, формат `.msi`).
2. Запустите скачанный файл и прокликайте **Next -> Next -> Install -> Finish**.
3. Снова дважды нажмите на `start-hotel.bat`.

## Ручной запуск через консоль (без скрипта)

В проекте уже лежит готовый встроенный Maven (`hotel-backend/maven`), поэтому устанавливать Maven отдельно **не нужно**.

### Вариант А — через встроенный Maven (PowerShell / CMD)

```powershell
cd hotel-backend
.\maven\bin\mvn.cmd spring-boot:run
```

Если в системе по умолчанию стоит старая Java 8/11, укажите путь к Java 17+ перед запуском:

```powershell
$env:JAVA_HOME = "C:\Users\ВАШЕ_ИМЯ\.jdks\ms-21.0.10"
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
cd hotel-backend
.\maven\bin\mvn.cmd spring-boot:run
```

### Вариант Б — сборка и запуск готового JAR-файла

```powershell
cd hotel-backend
.\maven\bin\mvn.cmd clean package -DskipTests
java -jar target\hotel-backend-1.0.0.jar
```

После появления строки `Started HotelApplication` откройте в браузере:
- **Рабочий интерфейс (Frontend + API):** `http://localhost:8080/`
- **Консоль базы данных H2:** `http://localhost:8080/h2-console` (JDBC URL: `jdbc:h2:mem:hoteldb`, User: `sa`, Password: *(пусто)*)

## Частые вопросы и полезные подсказки

- **Как пересобрать проект после правки кода вручную?**
  Запустите из консоли: `start-hotel.bat --rebuild`
- **Что делать, если вы удалили все номера или бронирования и хотите вернуть стартовые данные?**
  На дашборде появится кнопка **«Восстановить демо-данные»**, либо можно отправить POST-запрос на `/api/v1/system/reset-demo`. При каждом перезапуске сервера стартовые данные из `data.sql` также загружаются автоматически.
- **Почему при обычной опечатке (пустое поле, занятый номер) появляется аккуратная подсказка, а при вводе `999` гостей или `-500 ₽` — красный экран защиты?**
  Обычные ошибки пользователя обрабатываются стандартными сообщениями внутри формы. Экран защиты («Илья Валерьевич, перестаньте насиловать мой проект!») срабатывает только при реальных нештатных сценариях: экстремальных значениях (гости `> 10`, сумма `> 5 000 000 ₽`, отрицательные цены), попытках XSS/SQL-инъекций, повреждённых типах JSON или массовом флуде мутациями (`429 Too Many Requests`).

## Стек технологий

- **Язык и платформа:** Java 17+ (совместимо с JDK 17 / 21)
- **Фреймворк:** Spring Boot 2.7.18 (`Spring Web REST API`, `Spring Data JPA / Hibernate`, `Spring Security`, `Bean Validation`)
- **База данных:** H2 (встроенная, предзаполняется при старте через `data.sql`) / поддержка PostgreSQL (`pom.xml` включает драйвер PostgreSQL)
- **Сборка:** Maven (встроенная портативная версия в `hotel-backend/maven`)
- **Клиентская часть:** Vanilla HTML5, CSS3, JavaScript (встроена в сборку Spring Boot на порт `8080`)

## Основные REST API эндпоинты (`/api/v1`)

| Модуль | Эндпоинт | Назначение |
| :--- | :--- | :--- |
| **Номера** | `GET / POST /api/v1/rooms`, `PATCH /api/v1/rooms/{id}/status`, `DELETE /api/v1/rooms/{id}` | Управление номерным фондом и статусами |
| **Бронирования** | `GET / POST /api/v1/bookings`, `POST /api/v1/bookings/{id}/check-in`, `check-out`, `cancel` | Полный жизненный цикл брони с проверкой дат |
| **Гости** | `GET / POST /api/v1/guests`, `GET /api/v1/guests/search` | Регистрация и поиск постояльцев |
| **Платежи и счета** | `GET / POST /api/v1/payments`, `GET /api/v1/invoices/booking/{id}` | Кассовые операции и детализация счёта (Folio) |
| **Персонал и тарифы** | `GET / POST / PATCH / DELETE /api/v1/staff`, `/api/v1/tariffs` | Штат отеля и сезонные коэффициенты тарифов |
| **Отчёты** | `GET /api/v1/reports/occupancy`, `revenue`, `staff-kpi` | Загрузка фонда, структура выручки и KPI сотрудников |
| **Система** | `GET /api/v1/system/health`, `POST /api/v1/system/reset-demo` | Мониторинг состояния и восстановление демо-базы |
