## Описание проекта

Программный комплекс для автоматизации ключевых бизнес-процессов гостиничного предприятия, разработанный в рамках практической работы:
- **Управление номерным фондом** (категории номеров, статусы, поэтажная интерактивная карта 1–4 этажей);
- **Управление бронированиями** (проверка доступности дат, пересечений, расчёт стоимости по сезонам);
- **Проживание гостей** (Check-In заселение, Check-Out выселение, реестр постояльцев);
- **Учет персонала и смен** (роли сотрудников, отметка присутствия «На работе / Выходной», графики смен);
- **Финансы и тарифы** (управление тарифами, кассовые чеки/платежи, генерация и печать счетов-квитанций);
- **Аналитика и отчетность** (динамическая загруженность номерного фонда, выручка по способам оплаты, эффективность персонала).

## Технологический стек

### 1. Бэкенд (/hotel-backend)
- **Язык и платформа:** Java 17 или выше (LTS 17, 21), Spring Boot 2.7.18.
- **Веб-слой:** Spring Web (RESTful API, JSON-сериализация Jackson, CORS-фильтрация).
- **Безопасность:** Spring Security (контроль доступа к эндпоинтам, защита от инъекций и переполнения).
- **База данных:** H2 In-Memory Database (по умолчанию, стартует «из коробки») / PostgreSQL (поддержка через профиль `postgres`).
- **ORM:** Spring Data JPA / Hibernate (автоматическая генерация схемы и связи между сущностями).
- **Сборщик проекта:** Apache Maven (включает встроенный Maven в `hotel-backend/maven`).
- **Тестирование:** JUnit 5, Spring Boot Test (модульные и интеграционные тесты сервисов).
- **Консоль H2:** `http://localhost:8080/h2-console` (JDBC URL: `jdbc:h2:mem:hoteldb`, пользователь: `sa`, пароль пустой).
- **Тестовые данные:** Автоматически загружаются из `data.sql` при старте приложения.

### 2. Фронтенд (/hotel-frontend)
- **Технологии:** HTML5, CSS3, чистый JavaScript (Vanilla ES6+).
- **Интеграция:** Встроен в Spring Boot (статические ресурсы отдаются сервером по адресу `http://localhost:8080/`), а также поддерживает автономный запуск.

### 3. Контроль версий
- **Система контроля версий:** Git и GitHub.

## Как запустить проект

Перед запуском убедитесь, что на компьютере установлена **Java 17** или выше.

###Запуск готового JAR-пакета
В папке `hotel-backend/target` уже собран готовый автономный пакет приложения:
```bash
java -jar hotel-backend/target/hotel-backend-1.0.0.jar
```
После запуска откройте в браузере: **`http://localhost:8080/`** (веб-интерфейс отдается напрямую сервером).

### Вариант 2. Запуск через Maven из исходного кода
```bash
cd hotel-backend
mvn spring-boot:run
```
*(Если системный Maven не установлен в PATH, можно использовать встроенный: `.\maven\bin\mvn spring-boot:run`)*.

### Запуск фронтенда отдельно

1. Перейдите в папку `hotel-frontend`.
2. Дважды кликните по файлу **`index.html`** (откроется в любом браузере: Chrome, Edge, Firefox, Яндекс).
3. Приложение готово к работе! Если сервер Spring Boot запущен на порту 8080, в интерфейсе загорится зеленый индикатор связи.

## Особенности интерфейса

1. **Интерактивная карта номеров (Шахматка и Коридоры):** Наглядное визуальное представление фонда по этажам (1–4 этажи) со сменой статуса в один клик.
2. **Учет смен персонала:** Быстрое переключение статуса присутствия («На работе / Выходной») и фильтрация сотрудников по сменам.
3. **Фирменный бланк счёта:** Встроенный генератор счетов с реквизитами гостиницы, расчетом суток проживания и поддержкой вывода на печать (`Ctrl+P`).
4. **Финансовая аналитика:** Графики загрузки, динамика выручки и расчет эффективности сотрудников в реальном времени.
5. **Ролевой переключатель:** Демонстрация работы системы от лица различных ролей (Администратор, Портье, Горничная, Бухгалтер).
6. **Защита данных и уведомления:** Интеллектуальная валидация полей ввода, защита от инъекций и информативные всплывающие подсказки.
