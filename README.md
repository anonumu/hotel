## Описание проекта

Программный комплекс для автоматизации ключевых бизнес-процессов гостиничного предприятия, разработанный в рамках практической работы:
- **Управление номерным фондом** (категории номеров, статусы, поэтажная интерактивная карта);
- **Управление бронированиями** (проверка доступности дат, пересечений, расчёт стоимости по сезонам);
- **Проживание гостей** (Check-In заселение, Check-Out выселение, реестр постояльцев);
- **Учет персонала и смен** (роли сотрудников, зоны ответственности, графики смен);
- **Финансы и тарифы** (управление тарифами, кассовые чеки/платежи, генерация и печать счетов-квитанций);
- **Аналитика и отчетность** (загруженность номерного фонда, выручка по способам оплаты, эффективность персонала).

## Архитектура системы

### 1. Бэкенд (/hotel-backend)
- **Язык и платформа:** Java 8 (совместимо с Java 8, 11, 17, 21), Spring Boot 2.7.18.
- **База данных:** H2 In-Memory Database (не требует сторонней СУБД, стартует «из коробки»).
- **ORM:** Spring Data JPA / Hibernate (автоматическая генерация схемы).
- **Консоль H2:** `http://localhost:8080/h2-console` (JDBC URL: `jdbc:h2:mem:hoteldb`, пользователь: `sa`, пароль пустой).
- **Тестовые данные:** Автоматически загружаются из `data.sql` при старте.

### 2. Фронтенд (/hotel-frontend)
- **Технологии:** HTML5, CSS3, чистый JavaScript (Vanilla ES6+).
- **Дизайн:** Минималистичный, чистый светлый интерфейс без лишних эффектов и визуального перегруза, удобный и практичный.
- **Двухрежимная работа:**
  - **Live API:** Автоматически отправляет запросы к REST API Spring Boot на порту `8080`.

## Как запустить проект



### Запуск через консоль Maven
```bash
cd "hotel-backend"
mvn spring-boot:run
```

### Запуск фронтенда
1. Перейдите в папку `hotel-frontend`.
2. Дважды кликните по файлу **`index.html`** (откроется в любом браузере: Chrome, Edge, Firefox, Яндекс).
3. Приложение готово к работе! Если сервер Spring Boot запущен, в левом нижнем углу загорится зеленый индикатор связи.

## Особенности интерфейса

1. **Интерактивная карта номеров (Шахматка):** Наглядное визуальное представление всех номеров по статусам с возможностью смены статуса в один клик.
2. **Фирменный бланк счёта (Guest Invoice):** Встроенный генератор счетов с реквизитами гостиницы, расчетом суток проживания и поддержкой вывода на печать (`Ctrl+P`).
3. **Ролевой переключатель:** Демонстрация работы системы от лица различных стейкхолдеров (Администратор, Портье, Горничная, Бухгалтер).
4. **Уведомления (Toasts):** Плавные всплывающие сообщения об успешных операциях и валидационных ошибках.
